One job, packaged for your AI to install.

Some teams already use an AI assistant that can run agents, and someone on the team owns it. For them, lumic packages the job so that assistant can install it and run it: the written procedure, the tools the job needs, and the approval steps, fitted to your business.

Book a call What’s in a package

What’s in a package

Each package is a general core, written from a job lumic already runs, plus one file for your business. It is bundled as a plugin: one add-on that holds the whole job, which your AI assistant loads.

01

The written procedure

A skill: the procedure the agent follows, written like a standard operating procedure. Each step, each exception, and what the agent must not do on its own.

  • Exceptions go to a person, with the reason
02

The tools, when the job needs them

Some jobs need to reach a system directly. Then the package adds a command-line tool or an MCP server: a small connector the agent calls to read and enter records.

  • Added only when the job needs it
  • Access limited to the job
03

The approval steps

Where a person signs off, written into the procedure, with your system, its field names and your approval rules in your own file.

  • Gated by the people who know the work

How it’s sold

A setup fee, then monthly.
