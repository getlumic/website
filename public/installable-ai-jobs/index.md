# One job, packaged for your own AI agent.

Some businesses already run an AI agent, with someone on the team who owns it. For them, lumic packages one paid job so that agent can install it and run it: the written procedure, the tools the job needs, and one file for your business. A person on your team still approves what matters.

What the package holds

## A procedure, its tools, and your file.

Each package is a general core, built from a job lumic already runs, plus one file for your business. It is bundled as a plugin: one add-on that holds the whole job, which your agent loads.

### The skill

A skill is the written procedure the agent follows: each step, each exception, and what the agent must not do on its own.

- Written like a standard operating procedure
- Exceptions go to a person, with the reason

### Tools, only when the job needs them

Some jobs need to reach a system directly. Then the package adds a command-line tool or an MCP server, a small connector the agent calls to read and enter records.

- Added only when the job needs it
- Access limited to the job

### Your file

One file holds what is yours: the system you run, its field names, and your approval rules. The core stays general; your file makes it fit.

- Your system and field names
- Your approval rules
