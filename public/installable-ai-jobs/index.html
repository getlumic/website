Installable AI jobsFor your own AI agent

One job, packaged for your own AI agent.

Some businesses already run an AI agent, with someone on the team who owns it. For them, lumic packages one paid job so that agent can install it and run it: the written procedure, the tools the job needs, and one file for your business. A person on your team still approves what matters.

What the package holds

A procedure, its tools, and your file.

Each package is a general core, built from a job lumic already runs, plus one file for your business. It is bundled as a plugin: one add-on that holds the whole job, which your agent loads.

01

The skill

A skill is the written procedure the agent follows: each step, each exception, and what the agent must not do on its own.

  • Written like a standard operating procedure
  • Exceptions go to a person, with the reason
02

Tools, only when the job needs them

Some jobs need to reach a system directly. Then the package adds a command-line tool or an MCP server, a small connector the agent calls to read and enter records.

  • Added only when the job needs it
  • Access limited to the job
03

Your file

One file holds what is yours: the system you run, its field names, and your approval rules. The core stays general; your file makes it fit.

  • Your system and field names
  • Your approval rules

The jobs

Jobs lumic already runs, packaged.

Each package comes from a job lumic builds and runs for customers today, written down so another agent can do it the same way.

01

The order desk

The agent reads each purchase order that arrives by email and drafts the sales order. A person checks it before it goes any further.

  • Purchase-order email to draft sales order
  • A person checks each one

Accounts payable

The stock inbox

Questions

Installable AI jobs, in plain answers.

  • What is an installable AI job?

    One job a business pays for, packaged so its own AI agent can install and run it: a skill (the written procedure, with each step, each exception and what the agent must not do on its own), tools only when the job needs them, and one file for the business's systems and approval rules, bundled as a plugin.

  • Which AI agents can run it?

    The packages are built for AI agents that load skills and plugins, such as Claude. lumic confirms the fit for your agent in the free consultation.

  • Who approves what the agent does?

    A person on your team. The agent prepares the work, and the people who know it approve anything that sends, spends, posts or deletes.

  • What does it cost?

    Installable jobs: a fixed setup fee, then a monthly fee, quoted per job. The setup has a start and an end date; the monthly fee keeps the package current. Details: Pricing.
