The job, step by step

From the inbox to an unposted batch. A person posts it.

  2. 01

    A bill arrives by email.

    The agent reads each vendor bill as it arrives by email, the same bill a clerk would open.

  3. 02

    It matches the PO.

    It matches the bill to the purchase order in Sage 100.

  4. 03

    It prepares the batch.

    It prepares the AP invoice and the PO receipt in an unposted Sage 100 batch, ready for a person to review.

Flags

Flags before anyone pays.

When a bill does not match, the agent flags it for a person before it goes into the batch.

01

Price off the PO

The bill’s price is not the price on the purchase order. The agent flags the difference for a person to approve.

  • Flagged before anyone pays
02

Quantity off the PO

The bill charges for more or less than the purchase order. The agent flags it for a person to check.

  • Flagged before anyone pays
03

A duplicate invoice number

The vendor’s invoice number is already in Sage 100. The agent flags it, so the same bill is not paid twice.

  • Flagged before anyone pays
